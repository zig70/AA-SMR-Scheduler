# AA SMR Appointment Scheduler — Prompts Used to Build This

A chronological record of the human prompts that drove development of this project,
from initial brainstorm through to the release commit on `main`.

The project followed the **Spec-Driven Development (SDD)** process:
Brainstorm → PRD → Implementation Plan → TDD Vertical Slices.
