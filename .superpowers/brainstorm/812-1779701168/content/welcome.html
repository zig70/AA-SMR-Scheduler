AA SMR Appointment Scheduler

Designing the internal scheduling tool to replace spreadsheets and shared calendars

Three User Personas

📋 Booking Agent

Views the 7-day slot calendar, filters by service type, books customer vehicles, receives a unique reference number.

🔧 Mechanic

Sees their own today/tomorrow job list, opens appointments, adds timestamped work notes, updates status (Scheduled → In Progress → Completed).

🏠 Admin

Views today's full schedule across all mechanics — a single dashboard snapshot of the whole workshop floor.

Core Constraints from the Brief

✅ 7-day slot calendar view

✅ Filter by service type

✅ Double-booking prevention

✅ Unique booking reference

✅ Multi-branch / multi-location

🚫 No auth/login flows

🚫 No SMS/Email notifications

🚫 No rescheduling/cancellation

🚫 No payments/invoicing

🚫 No mobile-specific UI
